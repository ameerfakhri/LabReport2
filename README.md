# 🧬 Genetic Algorithm: 80-Bit Pattern Evolution

This repository contains an interactive Streamlit application that implements a custom **Genetic Algorithm (GA)** to evolve an 80-bit binary chromosome toward a predefined optimum. 

---

## 📌 Problem Specification & Constraints
The GA optimizes an 80-bit chromosome according to the following constraints:
* **Population Size ($N$)**: 300 individuals
* **Chromosome Length ($L$)**: 80 bits
* **Target Optimum**: Exactly 50 ones 
* **Max Fitness Score**: 80
* **Generations**: 50 iterations
